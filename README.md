# iOS AutoTap

适用于 **iOS / iPadOS 15.0 及以上系统**的自动点击与操作录制工具。AutoTap 面向 TrollStore 环境设计，提供跨应用悬浮控制、真实触摸模拟、脚本保存以及点击和滑动回放，并适配 iPhone、iPad、浅色模式与深色模式。

[下载最新版本](https://github.com/mango6i/iOS-AutoTap/releases/latest) · [直接下载 AutoTap v1.0.3](https://github.com/mango6i/iOS-AutoTap/releases/download/v1.0.3/AutoTap_v1.0.3.ipa)

## 四种工作模式

- **单点模式**：在一个目标位置循环点击，可设置点击间隔、按压时长和执行次数。
- **多点模式**：添加多个数字目标，按照 `1 → 2 → 3…` 的编号顺序循环执行。
- **点击录制**：记录连续点击位置，保存为独立脚本并重复运行。
- **手势录制**：同时记录点击与滑动轨迹，保存手势持续时间并进行回放。

## 主要功能

- 跨应用悬浮控制条，支持开始、暂停、继续和关闭。
- 数字目标可独立拖动和设置，运行时显示当前执行位置。
- 每个目标可分别设置点击间隔、时间单位、按压时长和执行次数。
- 支持无限循环、指定循环次数以及每轮完成后的等待时间。
- 四种模式配置相互独立，点击脚本与手势脚本分别管理。
- 支持脚本导入、导出、重命名和删除。
- 脚本和设置保存在应用数据目录，重新打开应用后仍可继续使用。
- 自动跟随系统浅色或深色外观。
- 支持运行时屏幕常亮、锁屏自动暂停及解锁后恢复待命状态。
- 可从应用内检查 GitHub Releases 新版本。

## 安装要求

- iOS / iPadOS 15.0 或更高版本。
- 推荐使用 **TrollStore** 安装。
- 跨进程悬浮窗和真实触摸模拟依赖 TrollStore 提供的系统权限。
- 普通自签方式即使能够安装，也可能无法使用跨应用悬浮窗或系统级触摸模拟。

## 使用方法

1. 从 [Releases](https://github.com/mango6i/iOS-AutoTap/releases/latest) 下载最新的 `AutoTap_vX.Y.Z.ipa`。
2. 使用 TrollStore 安装并打开 AutoTap。
3. 在首页选择需要的模式，创建或载入脚本。
4. 开启模式后，将目标点拖动到需要操作的位置。
5. 点击悬浮控制条的开始按钮运行；运行中可暂停、继续或关闭。

## 脚本导入与导出

导出的脚本默认保存到“文件”应用中的“我的 iPhone/AutoTap”目录。导入时会优先打开该目录，也可以从其他文件夹选择兼容脚本。
