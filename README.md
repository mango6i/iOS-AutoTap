# iOS AutoTap

适用于 iOS 15+ 的自动点击工具，提供单点、多点顺序点击和操作录制回放。应用针对 iPhone 与 iPad 自适应布局，并支持浅色、深色模式。

[下载最新版本](https://github.com/mango6i/iOS-AutoTap/releases/latest)

## 主要功能

- 单点模式：设置一个目标，按指定间隔持续点击。
- 多点模式：按照 `1 → 2 → 3…` 的编号顺序循环执行多个目标。
- 录制模式：记录手动点击位置，命名保存为独立脚本并回放。
- 独立参数：每个目标可分别设置点击间隔、时间单位、按压时长和执行次数。
- 循环控制：支持无限循环、指定循环次数以及每轮完成后的等待时间。
- 跨应用悬浮层：可移动控制条和数字目标，运行中显示当前执行位置与倒计时。
- 脚本管理：三种模式分别保存配置，支持导入、导出和删除。
- 数据持久化：脚本和设置保存在应用数据目录，重新进入应用后仍可使用。
- 系统适配：支持浅色/深色外观、运行时屏幕常亮和锁屏自动暂停。
- 更新检查：点击首页版本号即可检查 GitHub Releases 中的新版本。

## 安装要求

- iOS / iPadOS 15.0 或更高版本。
- 跨进程悬浮窗与真实触摸模拟依赖 TrollStore 提供的系统权限，建议使用 TrollStore 安装。
- 普通自签环境可能无法使用跨应用悬浮窗或系统级触摸模拟，这是 iOS 权限限制，并非脚本设置问题。

## 使用方法

1. 从 [Releases](https://github.com/mango6i/iOS-AutoTap/releases/latest) 下载最新的 `AutoTap_vX.Y.Z.ipa`。
2. 使用 TrollStore 安装并打开 AutoTap。
3. 选择单点、多点或录制模式，完成脚本配置。
4. 开启悬浮层，将数字目标拖到需要点击的位置。
5. 点击悬浮控制条的开始按钮运行；再次点击可暂停或继续。

## 脚本导入与导出

导出的脚本默认保存到“文件”应用中的“我的 iPhone/AutoTap”目录。导入时会优先打开该目录，也可以从其他文件夹选择兼容的脚本文件。
